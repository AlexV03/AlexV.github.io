The time rewind system works by adding a time rewind component to an object, which makes it record the object's transform and physics velocities. Each component can be assigned a group, and all time rewind components in the same group will be rewound together. This is handled by the time rewind manager, which keeps track of the groups.

void UBPC_TimeRewind::RecordSnapshot(float _deltaTime, float _worldTime)
{
	FsnapShots snapShot;

	snapShot.position = ownerRootComponent->GetComponentLocation();
	snapShot.rotation = ownerRootComponent->GetComponentRotation();
	if (ownerRootComponent->IsSimulatingPhysics())
	{
		snapShot.velocity = ownerRootComponent->GetPhysicsLinearVelocity();
		snapShot.angularVelocity = ownerRootComponent->GetPhysicsAngularVelocityInRadians();
	}
	snapShot.worldTime = _worldTime;
	snapShot.isInvalid = false;

	snapshots[currentIndex] = snapShot;

	currentIndex++;

	if (currentIndex >= maxSnapshots)
	{
		currentIndex = 0;
		hasLooped = true;
	}

	snapshots[currentIndex].isInvalid = false;
}

Part of the time rewind system is the RecordSnapshot function. It is called at every snapshot interval by the time rewind manager. When a snapshot is taken, the position and rotation are stored, and if the object has physics, the velocity and angular velocity are stored as well. All of this is saved together with the world time so the object can be rewound accurately. The snapshot is then saved at the correct index of the array using circular indexing. Circular indexing is used so that, instead of adding and removing a snapshot every time, the oldest snapshot is simply overwritten. This prevents constant memory allocations and the cost of shifting every element in the array.

When rewinding, the PlaySnapshots function is called. As long as the end hasn't been reached, it gets the previous snapshot and checks if it has been reached. If it has, the snapshot is marked as invalid, meaning it has been reached. Then the previous and current snapshots are taken from the array, and an alpha is calculated using the world time to smoothly lerp between the position and rotation of the two snapshots.

void UBPC_TimeRewind::PlaySnapshots(float _worldTime)
{
	if (hasReachedEnd)
		return;

    //End reach, return
	if (currentIndex == endIndex)
	{
		hasReachedEnd = true;
		return;
	}
	else
	{
		int prefIndex2 = currentIndex - 1;
		if (hasLooped)
		{
			if (prefIndex2 < 0)
				prefIndex2 = maxSnapshots - 1;
		}
		else
		{
			if (prefIndex2 < 0)
				prefIndex2 = 0;
		}

		if (_worldTime < snapshots[prefIndex2].worldTime)
		{
			if (!snapshots[currentIndex].isInvalid)
				if (currentIndex != endIndex)
				{
					snapshots[currentIndex].isInvalid = true;
					currentIndex--;
					if (currentIndex < 0)
						currentIndex = maxSnapshots - 1;
				}
		}

		int prefIndex = currentIndex - 1;
		if (hasLooped)
		{
			if (prefIndex < 0)
				prefIndex = maxSnapshots - 1;
		}
		else
		{
			if (prefIndex < 0)
				prefIndex = 0;
		}

		const FsnapShots& curSnap = snapshots[currentIndex];
		const FsnapShots& prefSnap = snapshots[prefIndex];

		float alpha = (curSnap.worldTime - _worldTime) / (curSnap.worldTime - prefSnap.worldTime);

        //Smoothly lerping between old and current snapshot using alpha
		FVector position = FMath::Lerp(curSnap.position, prefSnap.position, alpha);
		FRotator rotation = FMath::Lerp(curSnap.rotation, prefSnap.rotation, alpha);

		ownerRootComponent->SetWorldLocationAndRotation(position, rotation);
	}
}

struct FGroupRewind
{
	GENERATED_BODY()

	UPROPERTY(EditAnywhere, BlueprintReadWrite)
	int groupID = 0;
	UPROPERTY(EditAnywhere, BlueprintReadWrite)
	TArray timeComponents;
	UPROPERTY(EditAnywhere, BlueprintReadWrite)
	float worldTime = 0.0f;
	UPROPERTY()
	bool isRewinding = false;
	UPROPERTY()
	bool hasReachedEnd = false;
	UPROPERTY()
	bool isSelected = false;
};

Within the time rewind manager, the groups are stored using the GroupRewind struct, with each group stored in a seperate struct. When there is no rewinding, the manager updates each group and each time rewind component. If the player is rewinding time, the selected group gets rewound while the other groups will continue normally.
