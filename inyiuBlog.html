When switching between characters, the camera smoothly moves from the old character to the new character. This is done by interpolating between the two characters using an ease function, supplied with different values to custimize the movement. First, the camera accelerates until it reaches a maximum speed. As long as it isn't nearing the new character, the movement stays constant. When it gets close to the new character, deceleration kicks in and smoothly brings the speed down from its current speed to 0. The image below shows the variables that can be tweak to change the feel of the switching behavior.

With the camera system, it is also possible to zoom in and out when starting a conversation. This is similiar to the switching logic, except the camera moves to the character with a zoom-in offset applied. This also uses the ease function to smoothly move between the two positions.

Because the camera can end up behind objects that block the view of the controlled character, I made a see-through shader, using some resources, to learn more about shaders. With this shader, the character will always be visible behind objects that have been marked to be occluded. Only marked objects are affected, to make sure not all objects become see-through. For the shader, I am using a Material Parameter Colletion(MPC) and a material. The MPC stores the variables I want to change in Blueprints, so in the blueprints I can check whether I am behind something and make the see-through effect smoothly grow bigger or smaller. Then, within the material, I can access the parameters and use them to create the see-through shader.
