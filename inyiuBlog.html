When switching between characters the camera smoothly moves from the old character to the new character. This is done by smoothly interpelating between the 2 characters using a easefunction supplied with different values to custimize the movement, a acceleration speed is calculate until a max speed, then solong its not nearing the new character, movement stays constant, then when nearing the new character, deceleration kicks in and smoothly goes from its current speed to 0. The image below shows the variables that can be tweak to change to feeling of the switching behavior.

With the camera system it is also possible to zoom in/out when starting a conversation. This is similiar to the switching logic where the camera with a offset goes to the character with a zoomin offset. This also uses the easefunction to smoothly move between the two position.

Because the camera can get behind objects that block the view to the controleld character, i made a see through shader with the help of some resources, to learn more about shaders. With this shader the character will always be visible behind objects, that have been specied to be occluded, this to make sure not all objects are occluded for the character. For the shader i am using a Material Parameter Colletion(MPC) and a material. The MPC stores the variables I want to change in blueprints, so in the blueprints i can check if i am behind something and make the shader grow smoothly bigger or smaller. then within the material i can acces the parameters and use them to create the seethrough shader.
